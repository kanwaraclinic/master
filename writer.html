✍️ สร้างบทความใหม่

ใส่หัวข้อ กดปุ่ม แล้วระบบจะเขียนบทความและเพิ่มลิงก์ในหน้าแรกให้อัตโนมัติ

⚙️ ตั้งค่ากุญแจ GitHub
  1. เปิด หน้าสร้าง Token ของ GitHub (ล็อกอินบัญชี kanwaraclinic)
  2. ตั้งชื่ออะไรก็ได้ ตั้งวันหมดอายุตามสะดวก
  3. Repository access เลือก Only select repositories → เลือก master
  4. Permissions → Actions เลือก Read and write → Contents เลือก Read-only
  5. กด Generate token แล้วก๊อปปี้มาวางด้านล่าง

กุญแจจะถูกเก็บไว้ในเบราว์เซอร์ของเครื่องนี้เท่านั้น ไม่ได้อยู่ในเว็บไซต์ คนอื่นที่เปิดหน้านี้จะใช้งานไม่ได้

ตั้งค่ากุญแจก่อน จึงจะเห็นประวัติ
